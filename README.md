# Requirements

After a clean installation of `hyprland`, some dependencies are needed.

## Dependencies

- `wl-clipboard`
- `waybar`
- `hyprpaper`
- `hyprpicker`
- `hyprlauncher`
- `hypridle`
- `hyprlock`
- `xdg-desktop-portal-hyprland`
- `xdg-desktop-portal-gtk`
- `hyprsunset`
- `hyprland-qt-support`
- `hyprshutdown`
- `hyprland-guiutils`
